
 FlowList

FlowList is a clean, lightweight task management web application designed to help users organize their daily workflow and boost productivity.

---

 Features

Task Management: Effortlessly add, track, and manage your daily tasks.
Fast & Responsive: Minimalist UI designed for smooth performance across all devices.
Clean Interface: Intuitive layout focused on readability and ease of use.

---

 Tech Stack

HTML5: Semantic structure and content layout.
CSS3: Custom styling and responsive design.
JavaScript (ES6+): Interactive app logic and DOM manipulation.
